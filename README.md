## 🔐 Cyber Security

Ich möchte Sicherheitsprobleme nicht nur benennen, sondern ihre Ursachen verstehen:

- Wie entsteht eine Schwachstelle?
- Unter welchen Bedingungen lässt sie sich ausnutzen?
- Welche Auswirkungen hat sie tatsächlich?
- Wie lässt sie sich beheben und künftig vermeiden?

Sicherheitstests gehören für mich in eigene Testumgebungen oder in einen ausdrücklich autorisierten Rahmen. Zu einem guten Befund gehören eine nachvollziehbare Beschreibung und ein sinnvoller Lösungsansatz.
